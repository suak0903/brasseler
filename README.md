# Brasseler, Redesign-Entwurf

Unverbindlicher Gestaltungsvorschlag für die Website der **Gebr. Brasseler GmbH & Co. KG** (Lemgo), erstellt von **Dr.-Ing. Suat Akyol** am 02.10.2026 als Demonstration seiner Arbeitsweise mit KI-Werkzeugen.

**Entwurf:** https://suak0903.github.io/brasseler/ · **Über den Entwurf:** https://suak0903.github.io/brasseler/ueber-diesen-entwurf/ · **Original:** https://www.brasseler.de/

## Was das ist

Dies ist **nicht** die Website von Gebr. Brasseler und steht in keiner Verbindung zum Unternehmen. Sämtliche Texte, Bilder und Videos stammen aus der öffentlich erreichbaren Bestandsseite und bleiben Eigentum ihrer Rechteinhaber. Der Entwurf ist für Suchmaschinen gesperrt (`noindex, nofollow` und `robots.txt`) und wird auf Wunsch jederzeit entfernt. Anmerkungen an **contact@akyol.de**.

## Aufbau

Statisches HTML ohne Framework, ohne Build im Browser, ohne Datenbank. Alle 203 Seiten (Deutsch und Englisch, 124 News, 42 Chronik-Einträge) werden von einem Generator in `_src/` aus den Bestandsinhalten erzeugt. Details in `CLAUDE.md`.
